How to publish changes

1. Update entries and click Save entry.
2. Select Download content.js.
3. Replace content.js in your GitHub repository and commit the change.
4. Your public site updates after deployment.

Nothing is uploaded by this editor. Keep the downloaded file: unsaved changes disappear after refresh.
